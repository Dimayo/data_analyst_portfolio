# A/B-тест + кластеризация

[Notebook](research.ipynb) · Учебный кейс · Магазин спортивных товаров

**Стек:** Python, Pandas, NumPy, SciPy, Scikit-Learn, CatBoost, K-Prototypes, SQLAlchemy, Seaborn

Email-кампания с персональной скидкой: нужно было понять, стоит ли её масштабировать, и кому писать в следующих рассылках. Сначала оценил эффект на ARPU, затем сегментировал аудиторию и собрал propensity-модель для top-N таргетинга.

## Результат

- **A/B (ARPU):** 26 573 vs 22 271 → **+19.3%**, p < 1e-6, 95% ДИ разницы [2 723; 5 882] — кампания значимо сработала
- **Восстановление пола:** F1 = 0.95 — закрыли пропуски в профилях для сегментации
- **Propensity (клиент × товар):** CV / holdout ROC-AUC ≈ 0.91 — можно ранжировать клиентов под конкретный товар
- **4 кластера** с разными стратегиями: премиум, подростки, скидочная женская аудитория, низкая чувствительность к скидкам

## Что сделано

1. **Витрина** — SQLite + CSV, фильтрация по стране, унификация признаков покупок
2. **Gender** — логистическая регрессия по поведению покупок для пропусков
3. **A/B** — односторонний Welch t-test по ARPU, валидация через Monte-Carlo (10k разбиений)
4. **Кластеризация** — K-Prototypes, 4 сегмента и рекомендации по коммуникации
5. **Propensity** — CatBoost на парах (клиент, товар), GroupKFold по `id`, top-N для таргетинга

## Данные

Учебный датасет: `shop_database.db` (профили, коэффициенты, покупки), `personal_data.csv.gz`, списки treatment/control. Файлы в репозиторий не входят, расчёт и графики сохранены в ноутбуке.

## Вывод

Кампанию имеет смысл масштабировать: нижняя граница прироста ARPU около 2 700. Следующие рассылки лучше вести по четырём сегментам, а не одной скидкой на всех. Propensity — для top-N под конкретный товар, не для всей базы.
