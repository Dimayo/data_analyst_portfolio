# Гипотезы по конверсии

[Notebook](subscription_data.ipynb) · подписка на автомобили

**Стек:** Python, Pandas, NumPy, SciPy, Statsmodels, Seaborn, Matplotlib

Проверка продуктовых гипотез по CR и ответы на вопросы по трафику, устройствам и моделям авто (Google Analytics).

## Результат

Все три гипотезы отвергнуты (z-тест пропорций):

| Сравнение | CR | Вывод |
|---|---|---|
| Органика vs платный | **4.44%** vs 2.34% | органика выше ≈ на 90% |
| Desktop vs mobile | **3.32%** vs 2.8% | desktop выше ≈ на 19% |
| Москва/СПб vs регионы | **2.99%** vs 2.9% | столицы чуть выше (~3%) |
